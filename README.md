# Student Behavior Classifier

A simple machine learning project to classify student behavior based on academic performance and attendance.

### 🚀 Quick Start
1. **Data**: Uses a synthetic dataset of student grades and absences.
2. **Model**: Logistic Regression (Scikit-learn).
3. **Features**: Math, Science, and English grades + Absences and Issues.

### 🛠️ Tech Stack
* Python
* Pandas & NumPy
* Scikit-learn (StandardScaler, LabelEncoder, LogisticRegression)

### 📈 Current Result
The model predicts behavior and provides a confidence percentage for new inputs.
